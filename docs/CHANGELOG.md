# 更新记录

## 2026-10-30

- 新增清空回收站：永久删除前确认数量、默认取消，确认快照之外的新条目保留；部分失败可重试，扫描和重复 ZIP 导入不会复活已清空记录。
- 新票据初次按票种及商品内容自动分类，混合 ZIP 逐张判断；保留既有分类、人工修改及历史。
- 科研材料词库新增摄像头和 PLA，PLA 匹配不区分大小写，支持 PLA+ 及品牌前缀，避免误匹配其他英文单词内部的字母。
- 基础字段完整时仍按 PDF 坐标核对品名，避免单位或规格混入列表标题。
- 增加旧库回收站迁移、失败回滚与重试、自动分类、混合 ZIP、人工信息保留、品名分列及确认弹窗回归；CI 同步执行新增前端检查。

## 2026-10-29

- 新增住宿费分类，支持修改、筛选及历史记录。
- 分类按其他票据、出行交通、科研材料、铁路客票、住宿费固定顺序显示；零票据分类仍可筛选。
- 排除行程单附件在发票列表、统计、去重及台账导出中的显示，原文件和已有记录保留。
- 明确电子发票或增值税发票抬头优先保留，避免因发票备注提及行程单而隐藏真正发票。
- 增加行程单重复扫描、ZIP 导入、去重及导出回归，并覆盖住宿费保存、历史和固定分类顺序。

## 2026-10-24

- 生成入库单时同步生成统计表格，支持编辑和下载；每次生成视为一组，最多保留五组。
- 统计表类别固定为试剂、仪器、耗材；自动识别销售方，保留正常人工公司修改，网址和安全等级默认空白，安全等级仅接受试剂填写。
- 修复 PDF 标签与数值分层、数量与长单价相连、品名续行及竖排水印污染公司名的问题。
- 支持票面明确且可归属的单商品折扣，并核对折后总额；无法确认的行继续通过补填处理。
- 修复批量处理中某张失败导致后续发票未识别的问题，保留部分成功结果；旧失败任务可使用新识别逻辑，保留人工草稿。
- 固定统计表编辑窗口的标题和关闭按钮，长表单只滚动内容区域。
- 修复任务响应读取失败时可能提前释放正在运行任务的锁的问题。
- 新增合成 PDF、统计表编辑事务、公司迁移及整批识别回归；公开模板清除个人和办公软件元数据。

更新前请备份票据目录及 `app/data/`。旧成品不自动重写，重新生成后使用新的识别结果。代码只在本地处理票据，不引入云端识别。
